# MoosingAI

Revenue Idea Engine for MoosingAI.com. Scans public signals (Reddit, X) for small problems, ranks ideas by speed to revenue, and generates execution plans on demand.

Static site (index.html, style.css, app.js). Data is stored in localStorage. No backend or build step.

To refresh ideas, edit the IDEAS and PLANS objects in app.js and update the last-scan date in index.html.

The previous AI Resource Maximizer version is preserved at tag `v1-resource-maximizer`.
