# MoosingAI

AI resource inventory, maximizer, and quick revenue builder for MoosingAI.com.

## What it does
- Tracks your AI subscriptions, usage, costs, and renewals (localStorage).
- Surfaces revenue ideas scored for speed and fit with tools you already pay for.
- 10-day sprint template that validates before building.
- Simple ledger for revenue tracking toward the $4,000 / 30-day goal.

## Deploy to Hostinger
1. Upload the three files (index.html, style.css, app.js) as a static site, or zip and deploy via Node.js hosting if preferred.
2. Point MoosingAI.com DNS to the Hostinger IP.
3. Enable SSL in hPanel.
4. Connect Stripe and replace any placeholder links with real Payment Links.
